# Telegram's art in the preview

The Telegram preview draws Telegram's own chat pattern and small icons, copied from the apps' public source code (docs/plan/29-owner-list-2026-10-22.md section 8.4, D-6247, D-6270, task TGP-02). The apps publish that code under the GNU General Public License, so these files are Telegram's GPL art inside the private panel. **Every file in this folder must be replaced with art of xWriter's own before xWriter is ever given or sold to others (R-2528).** The same holds for anything the looks copy from the apps' code into their own files (for example the tails' shapes in `skins/`): it comes from the same repositories under the same licenses.

`icons.ts` hands the files to the looks (`--tg-art-*` custom properties); `../wallpaper/` draws the pattern. The fonts are not Telegram's art: they are in `../fonts/` with their own notice.

## Shapes written into the code

Each look's bubble tail, and Android's back arrow, are not files here: their shapes are copied from the same repositories (same commits and licenses as above) into the looks' code, and must be replaced with the files.

| Where                                        | Source in its repository                                                                                  | What it is                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `../skins/tails.ts` (`webTail`)              | telegram-tt `src/components/middle/message/MessageAppendix.tsx:5-27`                                      | Web A's tail                        |
| `../skins/webk.ts` (`tail`)                  | tweb `index.html:64-68` (`<symbol id="message-tail-filled">`)                                             | Web K's tail                        |
| `../skins/desktop.ts` (`tail`)               | tdesktop `Telegram/Resources/icons/bubble_tail.png` (traced from its @3x mask)                            | Desktop's tail                      |
| `../skins/android.ts` (`tail`)               | Telegram for Android `TMessagesProj/src/main/java/org/telegram/ui/ActionBar/MessageDrawable.java:794-796` | Android's tail                      |
| `../skins/ios.ts` (`tail`)                   | Telegram-iOS `submodules/TelegramPresentationData/Sources/ChatMessageBubbleImages.swift:193-239`          | iOS's tail                          |
| `../skins/android.css` (`--tg-android-back`) | Telegram for Android `TMessagesProj/src/main/java/org/telegram/ui/ActionBar/BackDrawable.java:122-145`    | Android's back arrow in the top bar |

Desktop's PNGs are white-on-black masks (the grey level is the coverage); every other file draws with its alpha. The research notes behind each file (sizes, where the apps draw them) are the measurement sheets of build upd29 (`.dev/upd29/tg/<look>.md` and `art/<look>/SOURCES.md`, kept out of the repository).
